# Paragraph Function Library

These are reasoning functions, not copy-paste sentence templates.

## P01 Background progression

Change → impact → concrete tension → scholarly need.

## P02 Problem narrowing

Observed phenomenon → existing explanation → unresolved mechanism → focal problem.

## P03 Concept definition

Major definitions → adjacent-concept distinction → selected definition → operational meaning.

## P04 Theory introduction

Core mechanism → typical explanatory scope → relevance → boundary.

## P05 Literature synthesis

Overall pattern → agreement → disagreement → reason for disagreement → dissertation position.

## P06 Literature conflict

Evidence A → evidence B → methodological/context difference → conditional interpretation.

## P07 Research gap

Known → unknown → why the unknown matters → what this dissertation addresses.

## P08 Hypothesis support

Relationship-specific mechanism → empirical support → focal-context relevance → hypothesis.

Do **not** narrate “derivation steps.”

## P09 Method choice

Evidence need → method fit → advantage over alternatives → output.

## P10 Data source

Where → when → who/what → acquisition → inclusion/exclusion → final analytic material.

## P11 Research procedure

Actual chronological research steps only.

Do not include author revision/thought process.

## P12 Results report

Answer → key statistic → uncertainty → hypothesis/RQ status → table/figure pointer.

## P13 Non-significant result

Direction → uncertainty → status → no false “no effect” claim.

## P14 Figure/table interpretation

What to inspect → central pattern → anomaly/contrast → relevance.

## P15 Mechanism discussion

Finding → mechanism → theory → literature comparison → scholarly consequence.

## P16 Counterintuitive result

Difference from expectation → plausible explanation → construct/context/method assessment → theoretical implication.

## P17 Qualitative theme

Theme proposition → meaning → evidence → recurrence → variation/counterexample → interpretation → RQ link.

## P18 Mixed-method integration

Evidence stream A → evidence stream B → convergence/deepening/dissonance/expansion → integrated judgment.

## P19 Theoretical proposition

Proposition → evidence basis → what it adds beyond original model → theoretical relation → scope.

## P20 Practice/design principle

Evidence → practical problem → principle → actor → condition → action → criterion → risk/boundary.

## P21 Theoretical contribution

Prior understanding → insufficiency → new distinction/mechanism → why it changes understanding → scope.

## P22 Methodological contribution

Prior identification limitation → new evidence chain/analytic ability → what becomes observable → transferability.

## P23 Practical contribution

Decision problem → evidence → specific action change → condition → expected benefit.

## P24 Limitation

Limitation → affected inference → what remains supportable → what cannot be generalized → next test.

Use in the dedicated limitations section, not scattered everywhere.

## P25 Future research

Unresolved issue → reason it matters → specific design/data needed → what it would adjudicate.

## P26 Chapter opening

Directly enter the substantive issue.

Avoid task-list meta prose.

## P27 Chapter closing

State what is now established and what substantive issue remains.

Do not mechanically preview the next chapter.
