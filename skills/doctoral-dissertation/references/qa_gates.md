# Dissertation QA Gates

A submission candidate should pass all gates.

## Gate 0 — Materials

- [ ] Current master manuscript identified
- [ ] Original instruments available
- [ ] Data/outputs available
- [ ] Qualitative material available if applicable
- [ ] Ethics facts confirmed
- [ ] Institutional formatting rules confirmed

## Gate 1 — Facts

- [ ] N consistent
- [ ] groups consistent
- [ ] time consistent
- [ ] instruments consistent
- [ ] procedures consistent
- [ ] methods consistent
- [ ] completion status consistent

## Gate 2 — Structure

- [ ] every chapter has one major function
- [ ] every section solves a sub-problem
- [ ] every subsection has one central judgment
- [ ] chapter interfaces are substantive, not meta-writing

## Gate 3 — Paragraphs

- [ ] one central claim per paragraph
- [ ] evidence exists
- [ ] evidence is interpreted
- [ ] no excessive fragments
- [ ] no overloaded paragraphs

## Gate 4 — Language

- [ ] finished-state voice
- [ ] no revision-history prose
- [ ] no derivation narration
- [ ] no scattered defensive caveats
- [ ] no habitual over-hedging
- [ ] no promotional inflation
- [ ] core terminology stable
- [ ] long sentences controlled

## Gate 5 — Literature

- [ ] synthesis by problem
- [ ] disagreements addressed
- [ ] theory performs analytic work
- [ ] gaps are substantive
- [ ] no repeated full theory definitions

## Gate 6 — Methods

- [ ] what/why/how/quality/output clear
- [ ] actual procedure reported
- [ ] author thought history excluded
- [ ] no preset-result language
- [ ] ethics statements factual

## Gate 7 — Results

- [ ] directly answer RQs/hypotheses
- [ ] body does not copy tables
- [ ] non-significant/counterintuitive findings retained
- [ ] uncertainty reported
- [ ] no limitation tails
- [ ] unresolved substantive questions identified where useful

## Gate 8 — Discussion

- [ ] mechanism explained
- [ ] literature relationship specified
- [ ] contradictions handled
- [ ] theoretical consequence articulated
- [ ] no automatic “future research” ending

## Gate 9 — Qualitative/Mixed

- [ ] qualitative facts consistent
- [ ] themes are analytical judgments
- [ ] quotes interpreted
- [ ] variation/counterexamples considered
- [ ] evidence streams genuinely integrated

## Gate 10 — Contribution

- [ ] theoretical contribution exceeds “significant path”
- [ ] methodological contribution exceeds “many methods”
- [ ] practical contribution changes action/decision
- [ ] strong claims have evidence anchors

## Gate 11 — Limitations/Future Research

- [ ] limitations concentrated
- [ ] each limitation affects a specified inference
- [ ] conclusions are not unnecessarily weakened
- [ ] future research follows from a concrete unresolved issue

## Gate 12 — Figures/Tables/Appendices

- [ ] every important figure/table has a function
- [ ] first reference precedes object
- [ ] body interprets key figure/table
- [ ] numbering continuous
- [ ] appendix references point to real evidence
- [ ] duplicate visuals removed unless justified

## Gate 13 — Citations/Footnotes

- [ ] semantic match checked
- [ ] bibliography entity exists
- [ ] citation style consistent
- [ ] multilingual entries consistent

## Gate 14 — Global Consistency

- [ ] title
- [ ] abstract(s)
- [ ] RQs
- [ ] methods
- [ ] results
- [ ] conclusion
- [ ] appendices
- [ ] other-language versions

all describe the same actual study.

## Gate 15 — Defense Readiness

The author can answer:

- [ ] Why this problem?
- [ ] Why this research design?
- [ ] Why these methods?
- [ ] What is the strongest finding?
- [ ] What genuinely changes existing understanding?
- [ ] What cannot be claimed?
- [ ] Which findings are exploratory?
- [ ] How can an examiner audit the core evidence?
