# Use Cases

## 1. Start a new dissertation

> Use the doctoral-dissertation skill. Do not inherit any prior project content. Read my current materials, build the Frozen Facts Table, Claim–Evidence Matrix, and RQ Closure Matrix, then propose the dissertation architecture.

## 2. Rewrite a literature review chapter

> Use the doctoral-dissertation skill to rebuild Chapter 2. Organize by scholarly problems and disagreements rather than author-by-author summary. Remove repeated theory definitions. Do not write meta-transitions or “to lay the foundation for the next chapter.”

## 3. Rewrite a results chapter

> Use the skill to rewrite the results. Keep full numbers in tables, write only the key judgments in the body, retain non-significant findings, and remove limitation tails from result paragraphs.

## 4. Rewrite a discussion

> Use the skill to strengthen the discussion. For each major result: explain the mechanism, compare with literature, state whether it supports/extends/qualifies/challenges prior theory, and articulate the theoretical consequence. Do not automatically end paragraphs with “future research is needed.”

## 5. Remove defensive/over-cautious prose

> Audit the dissertation for process narration, derivation narration, pre-defensive explanations, scattered limitations, and stacked hedge words. Keep true methodological boundaries, but rewrite the body in finished-state scholarly language and restore warranted theoretical strength.

## 6. Full audit before submission

> Use all QA gates. Prioritize factual integrity and evidence first, then inference, structure, language, figures/tables/appendices, citations, multilingual consistency, and defense readiness.
