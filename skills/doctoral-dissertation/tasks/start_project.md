# Start a Dissertation Project

## Purpose

Before writing prose, establish the real research state.

Do not begin by generating a seven-chapter outline from general knowledge.

## Step 1 — Inventory actual materials

Identify:

- current manuscript(s);
- proposal;
- published/submitted papers;
- datasets;
- instruments;
- interview materials;
- analysis outputs;
- figures/tables;
- appendices;
- ethics records;
- institutional template;
- language versions.

## Step 2 — Build the Frozen Facts Table

Freeze only facts supported by the project materials.

Required fields:

| Field | Required value |
|---|---|
| Current title | exact |
| Degree/discipline | exact |
| Core research object | exact |
| Research questions | exact current version |
| Dataset(s) | source + time |
| Sample(s) | N + recruitment |
| Assignment | random/non-random/NA |
| Instruments | actual administered version |
| Qualitative material | N + collection facts |
| Analyses completed | output exists |
| Planned but incomplete work | explicit |
| Ethics | only real approvals/consent |
| Current master file | exact |
| Required languages | exact |
| School rules | source |

Never “harmonize” conflicting facts by guessing. Resolve from the highest-quality original source.

## Step 3 — Build the Claim–Evidence Matrix

For every strong claim ask:

1. What evidence would this claim require?
2. Do we actually have it?
3. Is the evidence direct or inferred?
4. Does the wording exceed the design?

If the evidence does not support the claim:

- reduce the claim;
- reclassify the work;
- remove it;
- or obtain real evidence.

## Step 4 — Build the RQ closure matrix

| RQ | Evidence | Method | Result | Chapter | Final answer | Output |
|---|---|---|---|---|---|---|

Do not draft the final structure until each current RQ has a plausible evidence route.

## Step 5 — Separate completed work from planned work

Use a strict status ladder:

1. conceptualized;
2. designed/developed;
3. reviewed;
4. empirically tested;
5. independently validated;
6. implemented in real settings.

Use the correct status word in the thesis. Never skip levels.

## Step 6 — Decide what the dissertation is **now**

A proposal describes intended research.  
A dissertation reports completed research.

If the completed project differs from the proposal, redesign the dissertation around the completed evidence.

## Output

Before major drafting begins, produce:

- Frozen Facts Table;
- Claim–Evidence Matrix;
- RQ Closure Matrix;
- list of unresolved evidence gaps;
- proposed chapter functions.
