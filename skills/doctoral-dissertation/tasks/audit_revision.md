# Full Dissertation Audit and Revision

## Audit order

### Pass 1 — Facts
Check:

- N;
- groups;
- time;
- instruments;
- procedures;
- analysis settings;
- ethics;
- completed vs planned status.

### Pass 2 — Logic
Check:

- title;
- RQs;
- chapter functions;
- method-to-RQ mapping;
- result-to-RQ mapping;
- conclusion closure.

### Pass 3 — Evidence
Check:

- each central claim has an anchor;
- appendices actually contain cited evidence;
- no invented statistics;
- no unsupported validation claims.

### Pass 4 — Inference
Check:

- causal language;
- generalization;
- robustness language;
- exploratory vs confirmatory status.

### Pass 5 — Finished-state prose
Search for process/meta traces:

- this chapter will;
- next section;
- based on the above we derive;
- to avoid misunderstanding;
- original plan;
- current materials;
- later supplement;
- to address reviewer concerns.

Rewrite or delete.

### Pass 6 — Anti-over-hedging
Search for clusters such as:

- may to some extent;
- perhaps;
- appears to;
- preliminary;
- some reference;
- certain inspiration.

For each occurrence ask:

> Does the evidence actually require this hedge?

If not, strengthen.

### Pass 7 — Repetition
Distinguish legitimate functional repetition:

- abstract = compression;
- results = full reporting;
- discussion = interpretation;
- conclusion = synthesis.

If the same sentence appears unchanged in all four, rewrite.

### Pass 8 — Language
Check:

- long sentences;
- empty transitions;
- translated syntax;
- promotional words;
- vague pronouns;
- synonym drift of core constructs.

### Pass 9 — Figures/tables/appendices/citations
Use `tasks/finalize_document.md`.

## System-error rule

One local error may indicate a system defect.

If one:

- footnote is wrong → inspect all footnotes;
- term is inconsistent → search whole manuscript;
- figure number is wrong → audit chapter numbering/cross-references;
- abstract claim is too strong → audit all abstracts, conclusion, title, headings;
- method fact conflicts → return to original instrument/data and freeze the fact;
- chapter function changes → recheck RQs, roadmap, abstract, conclusion, contents.

## No revision-history prose in final body

Do not leave:

- “after revision”;
- “in the original version”;
- “currently”;
- “to be supplemented”;
- “based on available files.”

The final dissertation contains research, not project management.
