# Finalize the Dissertation Document

This file covers manuscript-level formatting and audit logic.  
Institutional rules always override defaults.

## Headings

Prefer a controlled hierarchy:

- Chapter
- Section
- Subsection

Avoid excessive fourth/fifth-level fragmentation.

Same-level headings should be grammatically parallel.

## Body emphasis

Do not randomly bold body text.

Use bold only where required by the institutional style or for rare deliberate emphasis.

## Tables

Default three-line table style where appropriate:

- top rule: 1.5 pt;
- header separator: 0.75 pt;
- bottom rule: 1.5 pt;
- no vertical rules;
- no unnecessary internal horizontal rules;
- repeat header rows across pages;
- fit within text area.

Institutional style overrides this default.

## Figures

For each figure/table, verify:

1. Why is it needed?
2. Where is it first cited?
3. What does the body text interpret after it?

If no substantive interpretation exists, reconsider whether the figure belongs in the main text.

## Figure/table order

Preferred order:

> first textual reference → figure/table → substantive interpretation

Avoid disconnected objects and numbering order errors.

## Appendices

Appendices are an audit layer, not a storage dump.

Use them for:

- instruments;
- stimuli/materials if relevant;
- supplementary statistics;
- robustness analyses;
- qualitative audit material;
- ethics/consent material;
- evidence too detailed for the body.

Every “see Appendix X” must point to real content.

## Avoid duplicate visuals

Do not repeat the same complete image in the body and appendix without a clear reason.

## Cross-references

Audit:

- chapter;
- section;
- table;
- figure;
- appendix;
- footnote;
- page references.

Whenever numbering changes, update all references.

## Footnotes and references

Footnotes are semantic, not merely numeric.

Audit:

> body meaning → citation marker → footnote/source → bibliography entry

Do not fix systematic misalignment by blind global shifting.

## Table of contents

Use one consistent depth across the dissertation unless institutional rules require otherwise.

## Multilingual versions

Freeze the master-language version before final translation.

Cross-check:

- title;
- abstract;
- N;
- coefficients;
- p values;
- CIs;
- construct names;
- RQs;
- hypothesis numbers;
- figure/table numbers;
- claim strength.

Do not allow one language to say “caused” while another says “associated.”
