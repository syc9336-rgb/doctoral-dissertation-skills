# doctoral-dissertation

An end-to-end Skill for doctoral-dissertation architecture, drafting, evidence
integration, language control, auditing, and submission readiness.

## Use it for

- rebuilding a dissertation from real project materials;
- chapter/section/subsection architecture;
- literature review, theory, and hypothesis writing;
- methods, results, and discussion;
- qualitative and mixed-method integration;
- evidence-to-practice translation;
- removing meta-writing, derivation narration, and defensive caveats;
- correcting habitual over-hedging;
- figures, appendices, citations, and cross-reference audits;
- multilingual consistency;
- defense and submission QA.

## Writing philosophy

The dissertation body should present the **finished scholarly state**:

> problem → evidence → result → interpretation → contribution

not:

> how the author thought → revised → derived → defended → previewed the next section

Keep the entire directory when installing this Skill.
