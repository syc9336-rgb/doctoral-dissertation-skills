# doctoral-dissertation

博士大论文全流程写作、结构、语言、证据与定稿 Skill。

## 适用任务

- 从开题、论文、小论文和原始材料重建博士论文；
- 设计章—节—小节结构；
- 写作或重写文献综述、理论、假设；
- 方法、结果、讨论的规范化；
- 质性与混合方法整合；
- 设计/实践研究的证据转化；
- 删除过程性、推导性、提前防御式正文；
- 修复过度克制造成的理论价值弱化；
- 审核图表、附录、脚注、交叉引用；
- 中外文版本一致性；
- 答辩和提交前 QA。

## Skill 的关键写作观

博士论文正文应该呈现**研究完成态**：

> 问题 → 证据 → 结果 → 解释 → 贡献

而不是：

> 作者怎么想 → 怎么改 → 怎么推 → 担心什么 → 下一节准备做什么
