# Contributing

Contributions are welcome.

## Ways to contribute

- open an Issue for a writing-rule problem or false trigger;
- propose new dissertation workflows;
- improve task routing;
- add discipline-specific optional references without contaminating the generic core;
- improve examples;
- fix ambiguity, duplication, or contradictory rules;
- add tests or validation scripts.

## Core contribution rule

Do not add a specific dissertation's case, sample, variable names, products,
stimuli, interview content, or proprietary research data to the generic core.

Project-specific knowledge belongs in the user's project context, not in this Skill.

## Pull requests

Please explain:

1. the problem being solved;
2. why the existing rule is insufficient;
3. the proposed behavior;
4. one positive example;
5. one failure/negative example when relevant.
